# shadcn/ui ベースのレースボードUI設計

## 目的

大会一覧とリザルト画面を shadcn/ui のコンポーネント・トークンを基盤として統一する。計測ボードをモチーフにした現行の温かい紙色、濃いインク色、オレンジのアクセントは維持し、データ閲覧と比較に集中できる視認性を高める。

## 範囲

- shadcn/ui を Next.js 16 / Tailwind CSS 4 の既存構成へ初期化する。
- 大会一覧、リザルト画面、選手選択、集計、比較範囲、グラフタブを shadcn/ui の部品と共通トークンで整える。
- ローディング、空状態、データなし、取得失敗を共通の表示パターンへ揃える。
- 既存の取得フック、データ変換、選手比較ロジック、Recharts の計算と描画データは変更しない。

## デザイン方針

### レースボードの表現

- 背景は紙色、本文はインク色を維持する。
- オレンジは選択状態、主要操作、重要な差分だけに使用する。装飾目的では使わない。
- 順位・周回数・タイムは等幅数字を使い、選手名や説明と明確に区別する。
- カードと区切り線は情報のまとまりを示すために限定し、入れ子のカードを作らない。

### shadcn/ui の適用

| 既存の役割 | 適用する部品 |
| --- | --- |
| シーズン・シリーズ・カテゴリー選択 | Select |
| 選手の前後移動と変更 | Button |
| 選手検索 | Input |
| 絞り込み、選手、集計値、通知 | Card |
| グラフ種別の切替 | Tabs |

`components/ui` に配置する shadcn/ui の部品は、テーマトークンを直接使う。ページ固有のレイアウトとデータ表示は既存のコンポーネントに残す。

## 画面構成

### 大会一覧

- ページ見出し、フィルター、件数、一覧を一つの視線の流れにする。
- フィルターは Select に統一し、変更時のシリーズ解除という既存動作を維持する。
- 一覧は意味的な表構造を保ち、スマホで収まらない列は横スクロール可能にする。
- 行はリンクとして全体を操作可能にし、ホバーとキーボードフォーカスを明確に表示する。

### リザルト

- 戻る導線、カテゴリー、レース見出しを上部にまとめる。
- デスクトップでは選手・集計・比較範囲を左、グラフを右に置く。モバイルでは縦に並べる。
- 選手選択では現在の検索、一覧、前後移動を残す。768px未満でリストを開いた場合、検索欄を自動フォーカスしない。
- 集計値は少数の比較しやすいカードにし、順位、平均ラップ、ベストラップを等幅数字で表示する。
- グラフタブは Tabs に置き換え、選択中の種別が明確になるようにする。

## 状態表示

- 読み込み中は内容の位置を保つプレースホルダーまたは簡潔なローディング表示を使う。
- データなし・周回なし・品質異常は、理由と次にできることを本文で示す控えめな通知パネルとする。
- 取得失敗時は大会一覧への導線と再試行リンクを残す。
- 既存の状態判定条件は変えず、表示コンポーネントだけを共通化する。

## 実装境界

- 変更する: `app/globals.css`、ページと表示コンポーネント、`components/ui`、依存関係設定。
- 変更しない: `hooks/useRaceData.ts`、`hooks/useMeetData.ts`、`hooks/useComparisonRiders.ts`、`lib/dataTransform.ts`、`lib/chartColors.ts`。
- shadcn/ui の初期化と必要な部品の追加で依存関係が増える場合は、追加理由を `package.json` の差分で確認する。

## 検証

- `npm run lint` と `npm run build` を実行する。
- 代表的な大会でカテゴリー切替、選手検索、前後移動、グラフタブ切替、集計値を確認する。
- 768px未満とデスクトップ幅で、一覧、選手選択、グラフ、状態表示に水平のはみ出しや操作不能がないことを確認する。
- スマホ幅で、選手リストを開いた時にキーボードが自動表示されないことを確認する。
