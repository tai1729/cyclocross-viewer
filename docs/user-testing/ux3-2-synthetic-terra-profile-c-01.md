## Good points

1. 目的大会が日付順一覧で早く見つかり、直接開けた。
2. 結果表から選手分析への説明と導線が分かりやすい。

## Negative / unclear points

1. `AJOCC`、`ME1`、シリーズなど、競技知識がない初見者には意味が分からない。
2. 「周回差」という名称から単周タイム差を即座に想像しにくい。
3. ラップの「下ほど速い」と順位の「上ほど良い」は方向が異なり、見落とすと読み違えそうである。
