## Repetition and decision rule

- 強いsignalの候補: 同じtaskで2人以上が同じ目的を失う、または3/4以上が同じ発見に失敗する。
- 1人の好み、1回の言い換え、色の嗜好は単独では実装根拠にしない。
- ただしP0の不能やデータ誤解は1件でも即時エスカレーションする。
- `Participant count` と `Occurrence count` が異なる場合、頻繁に起きた1人の摩擦と広く起きた摩擦を分けて解釈する。
- P0/P1は修正候補、P2/P3はUX3 backlogまたは追加調査候補。実データに基づく分類前に製品変更を始めない。
