### Evidence discipline

- Observation: what was seen or heard, with task and Participant ID.
- Interpretation: a possible explanation, explicitly labelled as a hypothesis.
- Uncertain finding: preserve competing explanations and state what evidence
  would be needed to resolve them.
- Quote: anonymized, short, and attributable only to a Participant ID.
